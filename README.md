# Optimising User, Group, Role Management with Access Control and Workflows

## Overview

Optimising User, Group, Role Management with Access Control and Workflows is a web-based application that helps organizations efficiently manage users, groups, roles, and permissions using Role-Based Access Control (RBAC). The system also automates workflows such as user registration, approval, role assignment, and permission management to improve security and operational efficiency.

---

- User Registration and Login
- Secure Authentication
- Role-Based Access Control (RBAC)
- User Management
- Group Management
- Role Management
- Permission Assignment
- Workflow Automation
- Admin Dashboard

- Responsive User Interface

## Role-Based Access Control (RBAC)

The system follows RBAC where:

- Admin has complete access.
- Manager can manage assigned users.
- Employee has limited access.
- Permissions are assigned based on roles.

---

## Workflow Process

1. User Registration
2. Admin Approval
3. Role Assignment
4. Permission Allocation
5. User Access
6. Activity Logging
